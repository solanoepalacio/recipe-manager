- GET /admin/users?page=1&perPage=10 -> PaginatedResponse<AdminUserResponse>
- POST /admin/users { name, email, password, householdId } -> AdminUserResponse
- PATCH /admin/users/:id { name?, email?, username?, gender?, dateOfBirth? } -> AdminUserResponse
- DELETE /admin/users/:id -> void
- POST /admin/users/:id/password-reset-url -> { url: string }
- GET /admin/households?page=1&perPage=10 -> PaginatedResponse<AdminHouseholdResponse>
- POST /admin/households { name } -> AdminHouseholdResponse
- PATCH /admin/households/:id { name } -> AdminHouseholdResponse
- DELETE /admin/households/:id -> void (cascade deletes all members, recipes, meal plans)
