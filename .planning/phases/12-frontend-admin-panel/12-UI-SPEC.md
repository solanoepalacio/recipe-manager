# Phase 12 — UI Design Contract

> Visual and interaction contract for the Frontend Admin Panel phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value | Source |
|----------|-------|--------|
| Tool | none — custom Tailwind v4 design tokens | apps/web/src/app/globals.css |
| Preset | not applicable | — |
| Component library | none (hand-rolled primitives) | existing codebase |
| Icon library | lucide-react | TopBar.tsx, Drawer.tsx |
| Font | Outfit (next/font/google, self-hosted) | globals.css + Phase 07-01 decision |

The admin panel lives at `/admin/*` and `/setup` routes. It shares the token file but uses a **visually distinct shell** — no user Drawer, no recipe nav. The admin shell is a dedicated layout with its own sidebar/tab nav, keeping admin and user UI clearly separated at the layout level.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, table cell padding vertical |
| sm | 8px | Compact element spacing, button padding vertical |
| md | 16px | Default element spacing, form field gaps, card padding |
| lg | 24px | Section padding, panel header padding |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Page-level top padding |
| 3xl | 64px | Not used in admin panel (mobile-less admin context) |

Exceptions:
- Table row height: 44px minimum (touch-target compliance per WCAG 2.5.5, even in desktop-primary admin context)
- Admin login form max-width: 384px (matches existing login form convention from Phase 07-04: `max-w-[24rem]`)

## Typography

All sizes derived from observed usage in existing components (TopBar, Drawer, RecipeCard, ConfirmDialog).

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 15px | 400 (regular) | 1.5 | Table cell content, form labels, drawer nav items |
| Label | 13px | 400 (regular) | 1.4 | Table column headers, helper text, timestamps, token prefixes |
| Heading | 18px | 600 (semibold) | 1.2 | Panel section titles, page titles, TopBar title |
| Display | 22px | 600 (semibold) | 1.2 | Admin panel section headings (Users, Households, etc.) |

Font: Outfit at all sizes. Letter-spacing: -0.3px on headings (matches TopBar convention).

Weights in use: 400 and 600 only — no 500, no 700.

## Color

All values from `apps/web/src/app/globals.css` — no new colors introduced in this phase.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FAFAF7` (`--color-background`) | Page backgrounds, admin panel main content area, form backgrounds |
| Secondary (30%) | `#F4F2ED` (`--color-subtle`) + `#E8E1D5` (`--color-sand`) | Admin sidebar/nav background (`subtle`), table header row (`sand`), card surfaces |
| Accent (10%) | `#5EBD6A` (`--color-accent`) | Active nav tab underline, primary save/submit buttons, new-record FAB or button |
| Destructive | `#D94F4F` (`--color-destructive`) | Delete buttons, delete confirmation text, destructive action labels only |

Accent reserved for: active section tab indicator, "Guardar" / "Crear" submit button backgrounds or underlines. Never used on read-only elements, table rows, or informational badges.

Supporting palette (read-only, no new tokens needed):
- Borders: `#E0DCD5` (`--color-border`) — table dividers, form field borders, card outlines
- Secondary text: `#8A8680` (`--color-secondary`) — helper text, timestamps, empty state body
- Placeholder: `#C8C4BD` (`--color-placeholder`) — input placeholder text
- Foreground: `#2C2C2A` (`--color-foreground`) — all primary text

## Interaction Contracts

### Admin Login (`/admin/login`)

- Form: email + password fields, submit button "Iniciar sesión"
- On success: redirect to `/admin/panel`
- On failure: inline error message below form (not toast) — "Credenciales incorrectas. Verifica tu contraseña e inténtalo de nuevo."
- Layout: centered card, max-width 384px, identical visual treatment to user `/login`

### Setup Wizard (`/setup`)

- Accessible only when no Admin record exists; `SetupGuard` (already implemented in backend) returns 404 after setup
- If admin exists and user navigates to `/setup`: redirect to `/admin/login`
- Form: password + confirm-password fields, submit "Crear cuenta de administrador"
- On success: redirect to `/admin/login` with toast "Configuración completada. Inicia sesión."
- Password fields use type="password", no show/hide toggle required

### Admin Panel Shell (`/admin/panel`)

- Desktop: sidebar (280px fixed) + main content area
- Mobile: top tab bar with section labels (abbreviated: Usuarios, Hogares, Alimentos, Unidades, Tokens)
- Active section: accent underline on sidebar nav item (matches Drawer active pattern: `border-b-2 border-accent`)
- No Drawer component — admin panel has its own navigation chrome
- Logout button at bottom of sidebar: "Cerrar sesión" in `--color-destructive`

### Data Tables (Users, Households, Foods, Units, Tokens)

- Table layout: full-width, no horizontal scroll on desktop (columns fit viewport)
- Column headers: 13px, weight 400, `--color-secondary`, `--color-sand` background
- Row content: 15px, weight 400, `--color-foreground`
- Row height: minimum 44px
- Actions column: right-aligned, "Editar" in foreground + "Eliminar" in destructive
- Delete tap → inline `ConfirmDialog` below row (not modal)
- Edit tap → BottomSheet on mobile / inline form expansion on desktop
- Pagination: reuse `PaginationControls`; page size options: 10, 25, 50

### Create/Edit Forms

- Trigger: "Crear [entity]" button — accent color — at top-right of section header
- Form renders in `BottomSheet` on mobile, inline panel below table header on desktop
- Required fields marked with `*` in label
- Save: "Guardar cambios" (edit) or "Crear [entity]" (create) — accent button
- Cancel: "Cancelar" — secondary text button, no background
- On success: dismiss form + toast "[Entity] guardado." (Sonner, existing Toaster setup)
- On error: inline error text below the relevant field, not a toast

### Raw Token Display (one-time)

- After `POST /admin/tokens` succeeds: `OneTimeDisplay` component renders
- Yellow/warning surface: `bg-sand` border `border-border` rounded-[8px] p-4
- Copy button: "Copiar" — accent text, copies to clipboard
- Warning copy: "Copia este token ahora. No se mostrará de nuevo."
- Dismiss: "Entendido" button closes the display — no auto-dismiss
- The raw token is never shown again after dismiss

### Password Reset URL Display

- Appears inline in the Users table row after admin clicks "Restablecer contraseña"
- Same `OneTimeDisplay` component reused
- Copy instruction: "Comparte esta URL con el usuario de forma segura. Expira tras su uso."
- URL displayed in monospace text (Tailwind `font-mono`) at 13px

## Accessibility

- All interactive elements minimum 44px touch target (rows, buttons)
- `aria-label` on icon-only buttons
- Form fields: `<label>` with `htmlFor` wired to input `id`
- Delete confirm buttons: `role` and focus management handled by existing `ConfirmDialog` pattern
- Admin login form: `autoComplete="email"` on email field, `autoComplete="current-password"` on password field
