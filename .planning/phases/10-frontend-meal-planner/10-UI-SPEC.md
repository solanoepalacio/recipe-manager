## Views and Interaction Contract

### View 1: Planner Page (`/planner`)

**Layout — mobile (default):**
- TopBar: hamburger left, "Planificador" center. Uses standard `#FAFAF7` background (not sand variant — planner is a list view, not a detail view).
- Week navigation row below top bar: `<` chevron (left), "Semana del DD - DD MMM" label (center), `>` chevron (right). Full-width row, `py-3 px-4`, `border-b border-border`.
- 7 day accordion rows below. Vertical list, no divider gaps between rows (dividers are `border-b border-subtle` on each row).

**Layout — desktop (>1024px):**
- 7-column grid instead of accordion (per `05_ui_views.md`). One column per day. Each column shows day name header + stacked meal entries + add button.

**Week toggle:**
- Toggle control above the week navigation row (or in a header area): "1 semana / 4 semanas" segmented control. Active option has `bg-foreground text-background` pill; inactive has `text-secondary`.
- 4-week view shows 4 stacked week navigation blocks, each with the same accordion structure.

### View 2: Day Accordion Row

**Collapsed state:**
- Row height: ~52px, `py-3 px-4`, `border-b border-subtle`.
- Chevron-right icon (`text-secondary`, 16px) on the left.
- Day name: "Lunes" — 15px weight 600 `text-foreground`.
- Date: "10 mar" — 13px weight 400 `text-secondary`, displayed inline after day name with `gap-1`.
- Summary text: comma-separated recipe names — 13px weight 400 `text-secondary`. When empty: "Sin recetas planificadas" — 13px italic `text-placeholder`.
- Tapping anywhere on the row expands it.

**Expanded state:**
- Row header: `bg-subtle` (`#F4F2ED`), chevron-down, day name bold, date — same structure as collapsed.
- Entry rows below header (within the same accordion panel):
  - Each entry: `py-3 px-4 border-b border-subtle`.
  - Recipe name: 15px weight 400 `text-foreground` (left).
  - Delete button: `×` icon (Lucide X, 16px) `text-secondary`, tap target 44×44px (right). No confirmation — matches wireframe spec ("Delete removes recipe from day without confirmation").
  - Meal type label: 12px weight 500 uppercase `text-secondary`, shown below recipe name inline (e.g., "DESAYUNO").
- Empty expanded state: "Sin recetas planificadas" — 13px italic `text-placeholder`, `py-3 px-4`.
- "+ Anadir receta" row at bottom of expanded panel: 15px `text-accent` (`#5EBD6A`), `+` icon left, `py-3 px-4`. Tapping opens the recipe picker bottom sheet.
- Multiple days can be open simultaneously (no mutual exclusion).

### View 3: Recipe Picker Bottom Sheet

Triggered by tapping "+ Anadir receta" in any expanded day row.

**Structure:**
- Scrim: `rgba(44,44,42,0.35)` covering full screen behind sheet.
- Sheet: `rounded-t-[20px] bg-background`, slides up from bottom. Max height ~80vh with scroll.
- Drag handle: 36×4px, `rounded-full bg-border`, centered, `mt-3 mb-4`.
- Title: "Anadir receta a [day name, DD MMM]" — 15px weight 600 `text-foreground`, centered, `mb-4 px-4`.
- Search bar: `bg-subtle rounded-[10px] px-3 py-2`, placeholder "Buscar receta…" `text-placeholder`.
- Recipe list: each row `py-3 px-4 border-b border-subtle`.
  - Recipe name: 15px weight 400 `text-foreground` (left).
  - Tapping a row: creates entry, closes sheet, entry appears in day accordion.
- No explicit confirm button — tapping the recipe name is the confirmation action.
- Meal type selector: shown below the search bar as a horizontal scroll row of pill chips. Active chip: `bg-foreground text-background rounded-[16px] px-3 py-1`. Inactive: `border border-border text-secondary rounded-[16px] px-3 py-1`. Meal types (Spanish): "Desayuno", "Almuerzo", "Cena", "Merienda", "Postre". Default selection: "Almuerzo".
- Dismiss: tap scrim or drag sheet down.

### View 4: Edit Entry (Phase 10 plan 04)

Entry edit is triggered by tapping a recipe name in an expanded day row (long-press or separate edit affordance TBD by executor — inline bottom sheet preferred over full-screen modal for this simple operation).

**Edit bottom sheet:**
- Title: "Editar entrada".
- Recipe field: shows current recipe name; tapping opens the recipe picker flow (same bottom sheet).
- Meal type selector: horizontal scroll chip row (same as picker).
- "Guardar" filled button: `bg-foreground text-background rounded-[20px] px-6 py-3`, full-width.
- "Eliminar entrada" destructive text link: 15px `text-destructive`, centered, `mt-4`. No inline confirm — tapping shows ConfirmDialog inline (matches Phase 09 pattern from `confirmDeleteId` pattern).

## States and Loading Contract

| State | Visual Treatment |
|-------|-----------------|
| Loading (initial fetch) | 7 skeleton rows, each ~52px, `rounded-[8px] bg-subtle animate-pulse`, replacing accordion rows |
| Empty week (no entries anywhere) | All 7 day rows collapsed with "Sin recetas planificadas" italic in each summary |
| Partial week (some days have entries) | Days with entries show comma-separated names; empty days show italic placeholder |
| Drag-drop in progress | Entry card at 90% opacity `opacity-90`, cursor `grabbing`, target cell highlighted with `border border-accent` |
| Optimistic update | Entry appears immediately in target cell; server error reverts with toast "No se pudo mover la receta. Inténtalo de nuevo." |
| Recipe picker loading | Skeleton rows in the bottom sheet list, 3 rows at ~48px each |

## Drag-and-Drop Contract

Uses `@dnd-kit/core` + `@dnd-kit/sortable` (already installed).

- Draggable: `MealEntryRow` items.
- Drop targets: expanded day rows (any `DayAccordion` panel).
- Drag handle: grip-vertical icon (Lucide `GripVertical`, 16px, `text-secondary`) on the left of each `MealEntryRow`. Only visible when day is expanded.
- On drag start: auto-expand target day (if collapsed) after 500ms hover.
- On drop: `PATCH /api/meal-plan/entries/:id` with new `date` and/or `mealType`. Optimistic update applied immediately.
- Cross-day drag is supported (drag from one day row to another).

## Accessibility Contract

- All icon-only buttons (delete `×`, drag handle, chevrons, week nav) have `aria-label` attributes.
- Day accordion rows use `aria-expanded` on the toggle button.
- Meal type chip group uses `role="group"` with `aria-label="Tipo de comida"`.
- Bottom sheet uses `role="dialog"` with `aria-modal="true"` and `aria-label` matching the sheet title.
- Focus trap inside bottom sheet when open; focus returns to trigger on close.
- Week toggle buttons: `aria-pressed` on active button.
