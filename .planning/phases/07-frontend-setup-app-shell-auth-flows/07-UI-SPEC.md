| Property | Value |

## Interaction Contracts

### Login Flow
1. User lands on `/login` — LoginPage renders, form empty
2. User types email/username in field 1, password in field 2
3. User taps "Iniciar sesión" — loading state on button (spinner replaces text, button disabled)
4. On success — redirect to `/` (which renders the recipes list shell)
5. On error — toast appears (error variant), form fields remain filled, button re-enables
6. Session detected on page load — redirect immediately to `/` without showing login form

### Protected Route Redirect
- Any unauthenticated request to a `(app)` route group → redirect to `/login`
- After login, redirect to the originally requested URL (or `/` as fallback)

### Drawer
1. Hamburger tap → drawer slides in from left, scrim fades in simultaneously
2. Scrim tap → drawer slides out, scrim fades out
3. Nav item tap → drawer closes, route changes
4. Active item highlighted with `#5EBD6A` 2px underline
5. "Cerrar sesión" tap → confirmation NOT required (design shows direct action); calls logout API, clears session, redirects to `/login`

### Loading States (UX-02)
- While any TanStack Query fetch is in-flight: skeleton placeholder replaces content (not spinner overlaid on real data)
- Skeleton color: `#F4F2ED` (matches input/surface fill — warm neutral)
- Skeleton animation: pulse (CSS opacity animation)
- TopBar and Drawer header do NOT skeleton — they are populated from AuthContext synchronously

### Toast Notifications (UX-03)
- Position: top-center on mobile, top-right on desktop
- Auto-dismiss: 4 seconds for success and info; 6 seconds for error (user needs more time to read)
- Variants: success (`#5EBD6A` accent), error (`#D94F4F` destructive), info (`#8A8680` muted)
- Toast background: `#2C2C2A` (dark), text `#FAFAF7`
- Max 3 toasts stacked; oldest dismissed first when limit exceeded

## Responsive Breakpoints

Phase 7 is designed mobile-first (375px phone frame in hi-fi). Breakpoint behavior:

| Breakpoint | Width | Shell behavior |
|------------|-------|----------------|
| Mobile | < 768px | Drawer navigation (hamburger + slide-in) |
| Tablet | 768px–1023px | Drawer navigation (same pattern, wider drawer at 320px) |
| Desktop | ≥ 1024px | Persistent sidebar (drawer pinned open, no scrim, no hamburger) |

Note: desktop sidebar behavior is inferred from UX-01 (responsive layout requirement). The hi-fi only shows mobile. The same color/typography tokens apply at all breakpoints.
