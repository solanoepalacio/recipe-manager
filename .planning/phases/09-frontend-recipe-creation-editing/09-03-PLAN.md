    - 'use client' directive
    - Props: `recipeId: string`, `steps: StepResponse[]`, `onMutationSuccess: () => void`

    - Mutations:

      - `deleteStepMutation`: `api.delete(\`/recipes/\${recipeId}/steps/\${stepId}\`)`, onSuccess: call `onMutationSuccess()`, onError: `toast.error('Error al guardar. Intenta de nuevo.')`
      - `reorderStepsMutation`: `api.put(\`/recipes/\${recipeId}/steps/reorder\`, { ids })`, onError: `toast.error('Error al reordenar. Intenta de nuevo.')`, onSuccess: call `onMutationSuccess()`
    - Body:
      - If `steps.length === 0`: empty state — `div className="px-5 py-8 text-center"` with `text-[15px] text-secondary` "Sin pasos aun" and `text-[13px] text-secondary` "Usa '+ Anadir paso' para comenzar."
      - `DndContext` with `closestCenter` collision detection wrapping `SortableContext` with `verticalListSortingStrategy`
      - `onDragEnd` handler: compute new order via `arrayMove`, call `reorderStepsMutation.mutate({ ids: newOrder })`
      - Map `steps` to `StepRow` components with `onDelete` and `onUpdate` handlers
      - Disable drag handles while `reorderStepsMutation.isPending`: pass `className` prop or use CSS on wrapper

      - On "Anadir": call `addStepMutation.mutate()` — disabled when `newStepBody.trim() === ''`
