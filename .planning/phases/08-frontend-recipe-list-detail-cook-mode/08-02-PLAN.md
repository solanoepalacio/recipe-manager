IMPORTANT — Slug vs ID:
The backend `GET /api/recipes/:id` only accepts UUID, NOT slug.
`RecipeListItem` provides both `id` and `slug`. The detail page receives `slug` from the URL.
Solution: Pass recipe `id` as a query param in the link from the list page: `/recipes/${recipe.slug}?id=${recipe.id}`.
The detail page reads `id` from `useSearchParams()` for the API call, and `slug` from `useParams()` for display/URL.
If no `id` query param (e.g., direct navigation), fall back to fetching the list to resolve slug -> id, OR show error.
