## Unsatisfied Requirements

### SKILL-03 — PARTIAL

**Issue:** `recipes_search.md` lines 25 and 100 reference `GET /api/foods?search=<name>`. The actual `FoodsController.findAll()` accepts no query parameters and silently ignores them. `recipes_create.md` correctly documents no search support. The two files contradict each other — an agent reading `recipes_search.md` before `recipes_create.md` will send a search param that the API ignores.

**Fix:** In `recipes_search.md`, change both occurrences of `GET /api/foods?search=<name>` to `GET /api/foods` and add: "The endpoint returns all foods without filtering — scan the array by name to find the desired food ID."

### SKILL-06 — PARTIAL

**Issue:** Share token operations are entirely absent from the skill bundle. The API implements `POST /api/recipes/:id/share` (generates a share token, returns `{ shareToken: string }`, status 201) and `DELETE /api/recipes/:id/share` (revokes the token). `recipes_get.md` documents the `shareToken` field but provides no path for an agent to generate or revoke a share link.

**Fix:** Add a "Manage share link" section to `recipes_edit.md` documenting both endpoints.
