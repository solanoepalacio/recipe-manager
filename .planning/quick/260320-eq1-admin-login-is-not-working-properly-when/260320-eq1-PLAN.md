<objective>
Fix admin login returning 403 by adding @Public() decorator to all admin-protected controllers.

Purpose: AnyAuthGuard is registered as a global APP_GUARD. It checks for user session (connect.sid) or API key. Admin routes use AdminAuthGuard (a separate guard checking admin.sid session), but AnyAuthGuard runs first and rejects the request with 403 because there is no user session or API key. The fix is to mark all admin routes @Public() (bypassing AnyAuthGuard) while keeping @UseGuards(AdminAuthGuard) to enforce admin-specific auth.

Output: All admin routes accessible with valid admin session; AnyAuthGuard no longer blocks admin endpoints.
</objective>
