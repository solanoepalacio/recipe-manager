    **Install @nestjs/axios** in apps/api:
    ```
    cd apps/api && yarn add @nestjs/axios axios
    ```

    **Create `apps/api/src/umami/umami.module.ts`:**
    - Import `HttpModule` from `@nestjs/axios`, register with `timeout: 2000`.
    - Import and provide `UmamiService`. Mark module as `@Global()` so any module can inject UmamiService without importing UmamiModule.
    - Export `UmamiService`.

    **Create `apps/api/src/umami/umami.service.ts`:**
    - Injectable service with constructor injecting `HttpService` from `@nestjs/axios`.
    - Read env vars via `process.env` (project convention — no ConfigService):
      - `UMAMI_URL`, `UMAMI_WEBSITE_ID`, `APP_HOSTNAME`
    - Single public method: `trackEvent(eventName: string, data: Record<string, string | number | boolean>): void`
    - If `UMAMI_URL` or `UMAMI_WEBSITE_ID` is not set, return immediately (no-op).
    - POST to `${UMAMI_URL}/api/send` with body exactly as specified in design.md:
      ```ts
      {
        type: 'event',
        payload: {
          website: process.env.UMAMI_WEBSITE_ID,
          name: eventName,
          data,
          url: '/shared/[token]',           // hardcoded literal — NOT the actual token
          hostname: process.env.APP_HOSTNAME,
        }
      }
      ```
    - Fire-and-forget: call `.subscribe({ error: () => {} })` on the observable. Do NOT await.

    **Create `apps/api/src/umami/umami.service.spec.ts`:**
    - Unit test with mocked HttpService.
    - Test 1: When env vars are set, calling trackEvent posts correct payload to /api/send.
    - Test 2: When UMAMI_URL is not set, trackEvent does NOT call httpService.post.
    - Test 3: When httpService.post throws/errors, no unhandled error propagates.

    **Update `apps/api/src/app.module.ts`:**
    - Import `UmamiModule` in the imports array.

    **Update `apps/api/src/recipes/recipes.module.ts`:**
    - No changes needed because UmamiModule is @Global().

    **Integrate in `apps/api/src/recipes/sharing/sharing.service.ts`:**
    - Inject `UmamiService` in `SharingService` constructor.
    - In `findByToken()`, after the recipe is found and before returning, call:
      ```ts
      this.umamiService.trackEvent('share-link-view', {
        recipeId: recipe.id,
        recipeName: recipe.name,
      });
      ```
    - The call is on the raw Prisma recipe object (which has `id` and `name`), BEFORE `toRecipeDetailResponse()` mapping.
